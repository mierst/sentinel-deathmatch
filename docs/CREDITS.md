# Credits

No third-party code is included in this repository (clean-room policy, see
CONTRIBUTING.md). The people and projects below informed this mod's design or
are formats/tools it interoperates with - credited with thanks.

- **Terje Bruoygard** - the (now unmaintained) DeathMatch mod remains the
  best-designed public reference for arena gameplay systems in DayZ:
  fast-respawn flow, a population-scaled play zone, and a no-economy mission
  approach. Studied as prior art; no code used.
  https://github.com/TerjeBruoygard/TerjeMods
- **InclementDab** - DayZ Editor, the community's standard scene-editing
  tool. Sentinel Deathmatch reads the Editor's `.dze` save format so
  operators can author arenas with the tool they already know. Format
  interoperability only; no code used.
  https://steamcommunity.com/workshop/filedetails/?id=2250764298
- **Bohemia Interactive** - DayZ, the Enforce Script samples in
  DayZ-CommunitySamples, and the modding documentation.
- **Community reference material** - the open repositories of
  DayZ-Expansion, VPP Admin Tools, and the community modding wikis, as
  publicly readable references for engine behavior. No code used.

If you believe your work should be credited here, please open an issue.
