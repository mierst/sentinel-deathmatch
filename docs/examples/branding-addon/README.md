# CommunityBrand example

This directory is a source layout for an original companion branding PBO.
Add your converted `data/community_logo.paa` before packaging. It contains no
Sentinel Deathmatch code, scripts, layouts, or assets.

You may adapt and distribute these example templates only as part of an
original companion branding add-on, preserving their attribution. See
[LICENSE.md](../../../LICENSE.md) for the exception's limits.

Keep `$PBOPREFIX$` at the PBO root. After packaging, reference the texture as
`CommunityBrand\\data\\community_logo.paa` in `leaderboard-theme.json`.
See [the branding guide](../../branding.md) for conversion, signing,
installation, and distribution requirements.
